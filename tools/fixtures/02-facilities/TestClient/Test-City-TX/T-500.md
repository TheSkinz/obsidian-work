# T-500 (fixture)

ROLLUP-SCALE fixture. This is the Syncrude 7-1F-1 defect copied verbatim in shape,
including the part that matters: a per-pass figure was recorded into the
`Heater total` row, `Per circuit` was derived by dividing it back down, convection
divided evenly (16 / 2 = 8) and radiant did not (31 / 4 = 7.75) — and the residue
was then absorbed by writing the radiant per-circuit count as `~4` and inventing an
uneven 3-vs-4-tube coil split to explain it.

**The `~4` is deliberate and must stay.** An earlier draft of this fixture wrote a
clean `4`, which made the ratio test fire and looked like proof. Replayed against
the real 2026-07-23 card it caught nothing: `~4` is not arithmetic, so the radiant
row dropped out and the surviving convection ratio of 8 read as clean. The hedged
number is where the error actually hides, so the fixture carries it.

Lint must flag ROLLUP-SCALE on this file — for the approximate count.

The Treat Gas row is a genuine single-pass section: `Heater total` equals
`Per circuit`, so its ratio is 1 and it must be exempted rather than counted as a
third disagreeing circuit count. It is here to prove the exemption works, because
F-501 and F-901 both carry real sections of this shape and must stay silent.

Valid `source`/`verified` frontmatter is present so this fixture isolates the
rollup rule and does not also trip OP-FRONTMATTER.
