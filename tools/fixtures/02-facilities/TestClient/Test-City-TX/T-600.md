# T-600 (fixture) — HEATER-TYPE-VOCAB

`heater-type` reads `crude charge heater`, which is a **descriptive service name**, not a
value in the canonical vocabulary (`crude | vacuum | coker | reboiler | other`). Lint must
flag HEATER-TYPE-VOCAB on this file.

This is the exact defect the rule was written for: on 2026-08-21, 14 of 41 live cards
carried an off-schema value, and the collisions were invisible one card at a time —
`vacuum heater` sitting beside `vacuum`, `coker heater` beside `coker`, and three separate
spellings across the crude family. Grouping the fleet by this field produced eleven buckets
where five would do.

Note the correct handling is already demonstrated here: `service` holds the descriptive
string. The fix for a real card is to move the description there and put a vocabulary value
in `heater-type` — never to widen the vocabulary to accommodate a one-off spelling.
