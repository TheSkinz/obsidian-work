**Tube geometry notes.**

**Convection.** 35-B-16453 reads "3 tubes each naphtha pass in convection 6"". 35-B-27354 writes the same as "3.6" tubes per pass", which means 3 × 6", not a size. OD 6.625" is standard for NPS 6. No schedule, wall, ID, length or metallurgy is printed. **DSP#25113.1's convection line (3.810" ID, 150 ft, A213 TP347, finned 11% Cr at 2.5/in) describes the hydrogen coil, not these tubes.** It is therefore not carried here.

**Radiant.** 35-B-16453 reads "15 tubes each naphtha pass in radiant 6"". **15 tubes per radiant pass is confirmed by Jesse (2026-09-19).** The P&ID thermocouple table numbers tubes up to 18, which fits 3 + 15 numbered through. ID 5.885" and A335 P5 are **DSP#25113.1's values; no drawing in hand states them.** The 0.370" wall comes from a coworker's pipe-data table supplied by Jesse on 2026-09-19. That table's source isn't stated, and it got the Vac's 8"/10"/12" schedules wrong. 6.625" less twice 0.370" gives 5.885", so the table and the bid agree. DSP#25113.1's "0.310" AW" was a typo, since 0.310" would give 6.005". The same table's 4.500" × 0.345" row (3.810") is the hydrogen coil, like the bid's convection line. Treat the radiant ID as unconfirmed until the heater data sheet or a field-measured clean ID settles it. Floor-fired with 14 burners and tubes along the walls in section; horizontal tubes are likely (inferred) but not stated.

**Hydrogen coil, not pigged.** 4 passes × 10 finned tubes, 4" 347 SS, convection only, with a bare outlet tube. The inlet is 70013CH-4" with a CS/347SS spec break per pass. The outlet goes to 70005FSH-8".
