## Purpose

This manual describes how USADebusk performs mechanical decoking of fired heater coils by water-propelled pigging. It covers the complete methodology from project inputs through rig-in, decoking, verification, and rig-out, together with the ancillary services that attach to a decoking scope.

It is written to serve two uses. As a proposal attachment, it carries the methodology so that each heater-specific execution SOP can stay focused on that heater. As a standalone document, it establishes how the work is actually performed for client personnel who have not worked with USADebusk before.

## What this manual is not

This manual is not an execution SOP. Every job receives a heater-specific execution SOP that states the actual circuit configuration, tube dimensions, connection details, pig progression, and operating parameters for that heater. This manual describes the method; the SOP governs the job.

This manual does not state durations. Schedule and hours are established in the project estimate and confirmed in planning, not in a methodology document.
